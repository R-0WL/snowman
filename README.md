# GRF -> Ray Tracer Cube ~ MR. FROSTY THE SNOWMAN


## Demostración de Ejecución

![alt text](<Grabación 2026-09-10 225527.gif>)


| Tecla | Accion |
| :--- | :--- |
| Flecha Izquierda / A | Rotación de camara hacia la izquierda|
| Flecha Derecha / D | Rotación de camarahacia la derecha|
| Flecha Arriba / W | Rotación de camara hacia arriba|
| Flecha Abajo / S | Rotación de camara hacia abajo|
| N | Cambiar entre día y noche |
|1 | Cambiar a material blanco sin textura |
| 2 | Cambiar a textura de lava |
| 3 | Cambiar a textura de rayos eléctricos/ ultra hieloso |
| Escape | Cerrar la aplicacion |

## Requisitos y Ejecución

### Pre-requisitos
- Tener instalado [Rust y Cargo](https://www.rust-lang.org/).

### Ejecutar el Proyecto
```bash
git clone https://github.com/R-0WL/snowman
cd snowman
cargo run --release
```
~ La textura solo se aplica a los tres cubos blancos principales. Los ojos,
nariz, boca, botones, brazos, sombrero y piso conservan sus materiales sólidos
para mantener legible el personaje.
