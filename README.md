# GRF -> Ray Tracer Cube ~ MR.SNOWMAN


## Demostración de Ejecución

![alt text](<Grabación 2026-09-10 214840.gif>)



| Tecla | Accion |
| :--- | :--- |
| Flecha Izquierda / A | Rotación de camara hacia la izquierda|
| Flecha Derecha / D | Rotación de camarahacia la derecha|
| Flecha Arriba / W | Rotación de camara hacia arriba|
| Flecha Abajo / S | Rotación de camara hacia abajo|
| N | Cambiar entre día y noche |
| Escape | Cerrar la aplicacion |

---

## Requisitos y Ejecución

### Pre-requisitos
- Tener instalado [Rust y Cargo](https://www.rust-lang.org/).

### Ejecutar el Proyecto
```bash
git clone https://github.com/R-0WL/snowman
cd snowman
cargo run --release
```
